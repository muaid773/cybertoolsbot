# 🛡️ CyberToolsBot

بوت تيليجرام يجمع مجموعة من الأدوات المفيدة في مجال **الأمن السيبراني** و**استخبارات المصادر المفتوحة (OSINT)**.

## 📌 الأدوات المتوفرة

- 🔍 **Username Finder**
  - البحث عن أسماء المستخدمين عبر عدة منصات اجتماعية.

- 🔗 **URL Analyzer**
  - فحص وتحليل الروابط واستخراج المعلومات المتعلقة بها.

- 🌐 **Domain Analyzer**
  - تحليل أسماء النطاقات واستخراج البيانات المرتبطة بها.

- 📞 **Yemen Phone Scanner**
  - كشف وتحليل الأرقام اليمنية.

- ⛅ **Weather Tool**
  - معرفة حالة الطقس حسب الموقع الحالي.

---

## 🚀 طريقة الاستخدام

1. افتح البوت في تيليجرام.
2. اختر الأداة المطلوبة من القائمة الرئيسية.
3. أرسل البيانات المطلوبة.
4. انتظر حتى يقوم البوت بالتحليل وإظهار النتائج بشكل منظم.
